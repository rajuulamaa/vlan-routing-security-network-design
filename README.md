# VLAN, Routing & Security Network Design

## Overview
Designed and configured a multi-site enterprise network simulation using Cisco Packet Tracer. The project focused on VLAN segmentation, dynamic routing, network services, and security implementation within a scalable enterprise environment.

## Environment
- Cisco Packet Tracer
- Routers and Layer 2 Switches
- VLAN Configuration
- Dynamic Routing Protocols
- DHCP & DNS Services

## Tasks Performed

### Network Design
- Designed a multi-site enterprise topology
- Connected routers, switches, and end devices
- Configured structured IP addressing

### VLAN Configuration
- Created and assigned VLANs
- Configured trunk and access ports
- Implemented inter-VLAN communication

### Routing Configuration
- Configured OSPF and EIGRP routing protocols
- Verified route propagation and network connectivity
- Tested redundancy and routing behavior

### Network Services
- Configured DHCP for automatic IP assignment
- Configured DNS services for hostname resolution

### Security & Troubleshooting
- Applied firewall and basic security configurations
- Performed connectivity testing and troubleshooting
- Verified network performance and communication between sites

## Skills Demonstrated
- Enterprise network design
- VLAN implementation
- Inter-VLAN routing
- OSPF & EIGRP configuration
- DHCP/DNS administration
- Network troubleshooting
- Cisco networking fundamentals

Successfully designed and tested a functional enterprise network environment with routing, segmentation, security, and network services configured across multiple sites.
